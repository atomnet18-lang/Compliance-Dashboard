# Dashboard Compliance 2569

หน้า Dashboard เปรียบเทียบ **เป้าหมายตามแผน** กับ **ผลการดำเนินงานจริง** ของแผนการกำกับดูแลการปฏิบัติตามกฎ ระเบียบ (Compliance) ประจำปี 2569 — ฝ่ายบริหารความเสี่ยงองค์กร (ฝบส.) การไฟฟ้านครหลวง

เผยแพร่ผ่าน GitHub Pages (อ่านอย่างเดียว) อ่านข้อมูลจาก `data.json`

---

## ขั้นตอนการทำงาน (บันทึกผ่าน Excel โดยตรง)

```
1) แก้ไฟล์ Excel:  CP_2569_บันทึกผลจริง_template.xlsx  (ชีต "บันทึกผล")
        ↓  กรอก % ผลจริงสะสมรายเดือน + สิ่งที่ดำเนินการ ของแต่ละกิจกรรม
2) แปลงข้อมูล:     ดับเบิลคลิก อัปเดตข้อมูล.command  (หรือ python3 build_data.py)
3) push:           GitHub Desktop หรือ git push       →  GitHub Pages อัปเดตอัตโนมัติ
```

ไม่ใช้ SharePoint แล้ว — บันทึกข้อมูลในไฟล์ Excel ไฟล์เดียว ชีตเดียว (แผนเดียว แบ่ง 5 ขั้นตอน)

---

## วิธีกรอกข้อมูล (CP_2569_บันทึกผลจริง_template.xlsx)

ในชีต **"บันทึกผล"** (แผนเดียว มีแถบสีฟ้าคั่นแต่ละขั้นตอน 1–5) กรอกเฉพาะช่องสีเหลือง:

| คอลัมน์ | กรอกอะไร |
|---|---|
| **ม.ค.69 … มี.ค.70** (ช่องเหลือง) | % ความคืบหน้า **สะสม** ของกิจกรรม 0–100 ในเดือนนั้น |
| **สิ่งที่ดำเนินการ \<เดือน\>** | สรุปสิ่งที่ทำในเดือนนั้น (แสดงในหน้ารายละเอียดของ dashboard) |
| **ปัญหา/อุปสรรค** | ใช้ภายใน — ไม่ถูกเผยแพร่บน dashboard |

- คอลัมน์ **น้ำหนัก** (สีเทา) = ค่าถ่วงน้ำหนักตามแผน ปกติไม่ต้องแก้
- **เป้าหมายตามแผน** (เส้นทองบน dashboard) กำหนดไว้ในสคริปต์ `build_data.py` แล้ว ผู้ปฏิบัติงานกรอกเฉพาะผลจริง
- ห้ามแก้หัวตาราง และห้ามเปลี่ยนชื่อชีต `บันทึกผล`

## คำสั่ง terminal (ถ้าไม่ใช้ GitHub Desktop)

```bash
cd ~/1_กฟน./2569/Dashborad_CP/DB_CP

python3 build_data.py                 # แปลง Excel -> data.json
git add data.json index.html build_data.py "CP_2569_บันทึกผลจริง_template.xlsx"
git commit -m "อัปเดตข้อมูล Dashboard Compliance"
git push origin main
```

ครั้งแรกที่ `git push` GitHub จะถาม username + Personal Access Token

> ใช้ **GitHub Desktop** ก็ได้: ดับเบิลคลิก `อัปเดตข้อมูล.command` ก่อน แล้วเปิด GitHub Desktop → Commit to main → Push origin

## ไฟล์ในชุดนี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้า Dashboard (อ่าน `data.json` แบบ fetch — อ่านอย่างเดียว) |
| `data.json` | ข้อมูลที่ dashboard แสดง (สร้างโดยสคริปต์ ไม่ต้องแก้มือ) |
| `CP_2569_บันทึกผลจริง_template.xlsx` | ไฟล์บันทึกผลจริง — แหล่งข้อมูลหลักที่แก้เอง |
| `build_data.py` | แปลง Excel → `data.json` (Python ล้วน ไม่ต้องลงไลบรารี) |
| `อัปเดตข้อมูล.command` | ดับเบิลคลิกเพื่อรัน build_data.py (สำหรับผู้ใช้ GitHub Desktop) |
| `logo.png` | ตราสัญลักษณ์ กฟน. บนหัว dashboard |

## เกณฑ์สถานะบน Dashboard

เทียบ % ผลจริงสะสม กับ % เป้าหมายสะสม ณ เดือนที่เลือก:

- 🟢 **ตามแผน/เกินเป้า** — ผลจริง ≥ เป้าหมาย
- 🟡 **ใกล้เป้า** — ต่ำกว่าเป้าไม่เกิน 15%
- 🔴 **ต่ำกว่าเป้า** — ต่ำกว่าเป้ามากกว่า 15%
- ⚪ **รอกำหนด** — ยังไม่ถึงช่วงเวลาตามแผน
